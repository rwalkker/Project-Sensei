# SENSEI Program Presentation

A professional, interactive HTML presentation for the SENSEI (Sustaining Excellence through Networked Skills, Education & Impact) program at PHX6.

## Latest Update (March 2026)

Updated with unified belt criteria:
- Individual UPH as consistent performance metric for both PAs and AMs
- Reduced total hours from 250 to 100 hours
- Baseline established at White Belt entry using 4-week rolling average
- Quality yield thresholds from 90% (White) to 98% (Black)
- Clear knowledge assessment formats for each belt level
- Certification authority for Brown and Black Belts

## Features

- 15 comprehensive slides covering the entire SENSEI program
- Warehouse/ninja themed design matching the program aesthetic
- Animated particles and transitions
- Keyboard navigation (Arrow keys, Spacebar)
- Click navigation with progress indicators
- Fully responsive design
- No external dependencies - runs in any modern browser

## Quick Start

1. Open `index.html` in a web browser
2. Navigate using:
   - **Arrow keys** (← →) to move between slides
   - **Spacebar** to advance
   - **Navigation buttons** at the bottom
   - **Dot indicators** to jump to specific slides

1. **Title Slide** - Program introduction with hero image

## Customization

### Update Content
Edit `slides-data.js` to modify slide content, add/remove slides, or update text.

### Adjust Styling
Edit `styles.css` to change colors, fonts, animations, or layout.

### Replace Hero Image
Replace `assets/sensei-hero.jpg` with your own image (recommended size: 1920x1080 or similar aspect ratio).

## Presentation Tips

- **Fullscreen Mode**: Press F11 for immersive presentation
- **Practice Mode**: Use arrow keys for smooth navigation
- **Remote Presenting**: Works great with screen sharing tools
- **Print Version**: Use browser print (Ctrl+P) to create PDF handouts
